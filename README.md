# Dark Themed Visualizer

A visualizer inspired from lively wallpaper, works using webgl and trigonometry to render the fluid movement.
<img width="1912" height="925" alt="image" src="https://github.com/user-attachments/assets/d35920e0-9d2b-4665-a50e-2b0e9f537abf" />
Creates fluid movement when you move your mouse around, fluids are generated using webgl, trigonometry and procedural generation for randomizing patterns.
All of patterns are created fractcal brownian motion and coordinate geometry.


#Tech Stack
-HTML
-Javascript
-CSS
-WebGL
